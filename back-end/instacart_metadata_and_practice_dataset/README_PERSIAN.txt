README / راهنما

فایل‌های instacart_departments_real.csv و instacart_aisles_real.csv شامل فهرست واقعی گروه‌ها و زیرگروه‌های مجموعه‌داده Instacart هستند که از نمایش عمومی داده در Hugging Face بازنویسی شده‌اند.

فایل‌های دارای پیشوند DEMO_SYNTHETIC ساختگی و صرفاً برای تمرین کدنویسی هستند و به هیچ وجه داده خرید واقعی Instacart نیستند.

DEMO_SYNTHETIC_X_prior.csv: ماتریس خرید آموزشی ساختگی، 1000 مشتری × 200 کالا.
DEMO_SYNTHETIC_Y_next_order.csv: ماتریس سفارش بعدی ساختگی برای ارزیابی.
DEMO_SYNTHETIC_products.csv: نام‌ها و گروه‌بندی کالاهای ساختگی.

برای تحلیل ادعایی بر داده واقعی، حتماً داده معاملات اصلی Instacart را از منبع عمومی دریافت کنید و این فایل‌های ساختگی را با استخراج واقعی جایگزین کنید.
Source metadata: https://huggingface.co/datasets/attik/Instacart-Market-Basket-Analysis/tree/main
